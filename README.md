Example 3: Read a Potentiometer

Objective

Read a potentiometer using the ESP32’s analog-to-digital converter (ADC) and record the raw and millivolt readings at five positions.

Materials

Original ESP32 development board

10 kΩ potentiometer

Breadboard and jumper wires

USB data cable

Computer with Arduino IDE
